# Agentic RAG

An AI-powered company assistant that combines document RAG,
SQL data analysis, and automatic visualization using Gemini.

## Features

- PDF document question answering
- Employee database querying
- Natural language → SQL
- Automatic chart generation
- FastAPI REST API
- Gemini LLM
- Chroma vector database

## Tech Stack

Python
FastAPI
LangChain
Gemini
ChromaDB
SQLite
Pandas
Matplotlib

## How to Run

1. Clone the repository
2. Create virtual environment
3. Install requirements
4. Add Gemini API key to .env
5. Run FastAPI

## Example

User:
"Show average salary by department as a bar chart"

The system generates the SQL query,
executes it, and creates a chart automatically.
